## 공개 범위

스킬 ZIP은 별도 승인된 파일만 사용합니다. 공개 대시보드에는 PRIVATE 기록에서 선별·검증한 **상위 수준 상태 요약**만 표시합니다. 요청 ID·리뷰 원문·영수증·비밀정보·내부 상세 작업 파일은 공개하지 않습니다. 상태는 게시일 기준으로 수동 반영되며 자동 동기화되지 않습니다. 자세한 협업 자료는 GitHub PRIVATE에서 관리합니다.
