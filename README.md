# L1Work

L1 업무용 스킬 패키지 및 별도 승인된 공개 자료를 제공하는 GitHub PUBLIC 저장소입니다.

## 바로가기

- **[CoWork 공개 대시보드 — HTML 웹페이지로 바로 보기](https://wonhwipark.github.io/L1Work/cowork-dashboard/)**  
  PC·모바일에서 바로 열리는 **샘플 화면**입니다. 실제 협업 진행 현황·리뷰 결과가 아니며 PRIVATE 자료는 포함하지 않습니다.
- [CoWork 공개 샘플 HTML 원본](docs/cowork-dashboard/index.html) — GitHub 파일 화면에서는 HTML 소스 표시
- [L1Work 전체 파일·스킬 ZIP 보기](https://github.com/wonhwipark/L1Work) — 기존 배포 파일 및 자료

## 공개 범위

스킬 ZIP은 별도 배포 승인된 파일만 사용합니다. 공개 대시보드는 합성 샘플 데이터만 포함하며, 실제 CoWork 프로젝트·REQUEST/READY·리뷰·영수증·내부 상태 파일은 게시하지 않습니다. 내부 협업 현황은 별도의 GitHub PRIVATE 저장소에서 관리합니다.
