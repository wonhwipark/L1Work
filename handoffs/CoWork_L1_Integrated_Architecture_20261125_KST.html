CoWork와 L1Work는 설계·협업 및 승인된 전달 공간입니다. 업무 원본은 허용된 업무 환경에서만 보존합니다. 모바일 MCP는 업무 기능 접근 경로이고 Viewer는 별도 웹 UI입니다.

02 역할과 수정 범위

DESIGN

설계 GPT / CoWork

공통 아키텍처·스킬 요구·접근 가능한 개발/시험·Claude 독립 리뷰·GPT 판정·인계 관리. 업무 호스트 실제 설치·제품 소스를 직접 확인했다고 간주하지 않음.

WORK DESIGN

업무 GPT

실제 활성 스킬·권한·원본 revision 검증, 현장 설계와 실행 지시, 결과 수락 기준·판정. 공통 저장/UI 결손은 해당 담당으로 분리.

EXECUTION

Linux Agent / Qwen

업무 GPT의 작은 단위 지시를 받아 허용된 작업을 구현·실행하고 실제 action·근거·영수증·미확인을 회수. 자체 승인 부여 금지.

Recovery r0006

비-timeout Seed에서 원인 규칙과 잔존 보호 누락 검증, 후보별 검출/복귀안 및 MSC 의미 검증. Kernel/Viewer 내부 변경은 제외. 첫 사례 순차 실행.

Updater r0002

직접 지식 분석 또는 기존 Work 재사용, 근거·Coverage·MSC 품질, 개인 Knowledge 및 그룹 Preview. Workflow/Kernel/Viewer·Analyzer/Converter 내부 변경은 제외.

공통 스킬 / 저장 / UI

Analyzer는 사실 추출, Converter는 표현 변환, Workflow는 Work 흐름, Kernel은 원본·Evidence, Viewer는 저장된 결과 표시. 각자 별도 개선·시험.
