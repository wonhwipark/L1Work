상태 데이터와 갱신 방식

이 화면은 2026년 11월 12일 확인된 기록의 공개용 요약 스냅샷입니다. PRIVATE 업무 자료 원문, 요청 식별자, 상세 피드백, 자격증명은 포함하지 않습니다.

Pages는 공개 파일 변경 시 다시 배포되지만, PRIVATE 기록을 PUBLIC으로 자동 동기화하지 않습니다. 새로운 업무 상태는 별도 확인·공개 범위 검토 후 반영합니다.
